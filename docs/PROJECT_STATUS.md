## Operating rules learned the hard way (2026-08-28)

- **Do not commit or edit importable code while a pod is running** -- `core/`, `data/`, `models/`, `scripts/`. Pods mount this repo by hostPath and DataLoader workers re-import module source each epoch, so a mid-run edit can kill a healthy job (K-23 did exactly that to SCREEN-013). Check `kubectl get pods` first. Docs are safe; they are never imported.
- **A screening run is not a result.** `REGISTERED_SCREENING_RUN_READY` allows exactly one seed, refuses all Test access, and requires `decision_threshold` in the config before the run. The threshold is **0.04**, set from BASELINE-011's observed seed spread (0.2732-0.3122, SD 0.0196) so a promotion decision cannot be fitted to the result afterwards. A screen that clears it earns a three-seed confirmation, never a claim.
- **`git add` explicit paths, never `-A`.** `results/**/*.pt` is gitignored; a run directory holds multi-GB checkpoints.
